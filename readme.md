为什么会有Project_Domion？
==========================

Project_Domion 是致力于让任何人和任何机器都能体验到全模态的本地ai陪伴的项目。

Domino有什么作用？
==================

1.Domino致力于全模态的陪伴和快捷的互动。
2.现在的智能设备上设备助手已经习以为常，但Domino主要致力于能为大家在夜深人静的时候还有一个人能和你一起工作和娱乐。
3.Domino的各个功能开发相对简单，借助ai工具每个人都能为Domino最基础的组件、或是硬件控制主键进行修改和创作。

相比于寻常的陪伴型Agent,Domino有什么特点？
==========================================

Domino致力于在消费级设备上本地运行，即便没有可以用来加速推理的GPU或是付费的大模型提供商，本地优化过的语言（支持音色克隆）、大模型推理和简洁的模型答复会是我们的主要努力方向。
在下面给出的开发环境中，开启桌面视觉、本地麦克风转文字、本地大模型推理、本地文字合成语言（含音色克隆）的Dominon的已经能做到稳定4s的回复延迟。

Domino不能使用网络的模型提供商吗？
==================================
Domino后续将会提供完整的各项功能自定义网络提供商接口，用户可以自行配置
